# Questionary — Question Bank Generator

A lightweight, browser-only question bank builder. No install or API key is required.

## Run it

Open `index.html` in a modern browser. Paste source notes (or click **Load sample**), choose question count and types, then click **Generate question bank**. Export downloads a JSON file; Copy puts the questions and answers on your clipboard.

TXT, Markdown, and CSV files can be loaded from the upload tab. The PDF/DOCX selector is shown as a UI affordance, but this standalone demo does not extract those formats.

## Note

This is a front-end prototype. It uses built-in sample question templates and simple topic detection; it does not call an AI model or backend. Connect a generation API to produce questions grounded in arbitrary source documents.
